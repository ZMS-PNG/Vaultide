# 知洄 Vaultide 多维知识空间版广告视频

45 秒、1920×1080、30fps 的可编辑 Remotion 源文件。

视频只使用真实产品界面、已验证功能和本地品牌资产，重点展示：

- 外部权威资料进入互动课堂；
- Obsidian 单篇笔记与项目文件夹学习；
- 原笔记只读、双重确认的受控回写；
- 逻辑链、主题岛、来源流、时间演化四种空间透镜；
- 知识簇聚焦、内部关系与证据回查。

## 本地预览

```console
pnpm install
pnpm dev
```

## 渲染

```console
pnpm exec remotion render VaultideMultispace2026 out/video.mp4
```
